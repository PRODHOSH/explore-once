# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- `browser-script-compiler`: explore once, compile to a script, replay, repair only the broken step.
- `web-image-generation`: generate images through a signed-in ChatGPT or Gemini.
- `gallery-harvest`: turn a whole gallery page into a few numbered contact sheets.
- `form-filler`: fill a form, then stop for approval; submit needs an approval code.
- `ui-regression-suite`: health checks and visual diffs at desktop and mobile sizes.
- Shared Chrome helper, validator, and local-fixture tests.
